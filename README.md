<h1>🕒 Projeto: Hora do Dia</h1>

<img src="https://github.com/joao-robertoo/projeto-horadodia/blob/main/projeto-horadodia.PNG?raw=true"/>
<br>

<h2>👋 Sobre o Projeto</h2>

Este projeto é uma aplicação web simples desenvolvida com HTML, CSS e JavaScript que verifica a hora atual ou permite ao usuário inserir um horário para exibir uma saudação ou mensagem correspondente ao período do dia.

O objetivo foi praticar interação com data/hora, manipulação do DOM e lógica condicional, além de entregar uma interface clara e responsiva. 
<br> 
<br>

<h2>🧠 O que o Hora do Dia faz</h2>

Com este projeto, o usuário consegue:

* Ver a hora atual ou inserir manualmente um horário
* Detectar o período do dia (manhã, tarde, noite)
* Exibir uma saudação ou mensagem apropriada conforme o horário informado
* Atualização dinâmica da interface com base na entrada ou hora real

O foco é tornar a experiência simples, intuitiva e direta para qualquer usuário. 
<br> 
<br>

<h2>🧰 Tecnologias Utilizadas</h2>

* **HTML5** — Estrutura da aplicação
* **CSS3** — Estilização leve e responsiva
* **JavaScript** — Manipulação de data/hora, lógica condicional, DOM e interação dinâmica
<br>
<br>

<h2>📱 Responsividade</h2>

O layout foi desenvolvido para funcionar adequadamente em:

💻 Computadores
📱 Dispositivos móveis

Garantindo boa visualização e usabilidade em diferentes tamanhos de tela. 
<br> 
<br>

<h2>🎯 Objetivo do Projeto</h2>

Este projeto foi criado para praticar:

* Trabalhar com data/hora no JavaScript
* Condicionais e lógica de fluxo
* Manipulação de DOM
* Interface interativa simples

É uma boa demonstração de como usar lógica de programação básica para entregar funcionalidades úteis e interativas. 
<br>

# 🇺🇸 English Version

<h1>🕒 Project: Time of Day</h1>

<img src="https://github.com/joao-robertoo/projeto-horadodia/blob/main/projeto-horadodia.PNG?raw=true"/>
<br>

<h2>👋 About the Project</h2>

This project is a simple web application built with HTML, CSS, and JavaScript that displays the current time or allows the user to input a time to show a greeting or message corresponding to the period of the day.

The goal was to practice working with date/time, DOM manipulation, and conditional logic, while delivering a clean and responsive interface. 
<br> 
<br>

<h2>🧠 What Time of Day Does</h2>

With this project, the user can:

* View the current time or manually enter a time
* Detect the time period (morning, afternoon, evening)
* Display an appropriate greeting or message based on the provided or current time
* Dynamically update the interface according to the input or real time

The focus is on providing a simple, intuitive, and straightforward user experience. 
<br> 
<br>

<h2>🧰 Technologies Used</h2>

* **HTML5** — Application structure
* **CSS3** — Light and responsive styling
* **JavaScript** — Date/time handling, conditional logic, DOM manipulation, and interactive behavior
<br>
<br>

<h2>📱 Responsiveness</h2>

The layout works well on:

💻 Desktop devices
📱 Mobile devices

Ensuring good viewing and usability across different screen sizes. 
<br> 
<br>

<h2>🎯 Project Goal</h2>

This project was built to practice:

* Handling date/time in JavaScript
* Conditional logic and control flow
* DOM manipulation
* Creating a simple interactive interface

It’s a good demonstration of how basic programming logic can deliver useful and interactive features. <br> <br>
